# Senior Creative Developer Portfolio

An avant-garde, high-performance single-page developer portfolio built with **React**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**.

---

## ⚡ Highlights & Key Sections

1. **Hero Section**:
   - Animated staggered headline & fluid creative bio.
   - **"Available for work"** live status badge with pulsating radar indicator.
   - **"View Work"** interactive CTA smoothly guiding visitors to the showcase.
   - **Download CV** button with micro-animations and confetti trigger (`Alex_Rivera_Resume.pdf`).
   - Interactive **Live Telemetry HUD** (60 FPS vitals, tech pipeline, manifesto).

2. **Projects Section**:
   - 3 interactive featured project cards (*AetherOS 3D Spatial Canvas*, *Nexus Protocol DEX*, *Synthetix AI Studio*).
   - Live demo links (`Live Experience`) & GitHub repository links (`Source Code`).
   - Interactive tech stack tags and category filters.
   - Modal inspector for deep project exploration.

3. **Skills Section**:
   - Categorized skills: *Creative Frontend & UI*, *Backend & Systems*, *Tooling, 3D & Performance*.
   - Animated proficiency progress bars and hover scale animations.
   - Interactive category switcher tabs powered by Framer Motion `layoutId`.

4. **Experience Timeline**:
   - Interactive vertical timeline with glowing milestone spine.
   - Expandable / collapsible cards revealing key deliverables, metrics, and technology chips.

5. **Contact Section**:
   - Interactive message dispatch form with encrypted transmission aesthetic and confetti celebration.
   - **One-click Copy-to-Clipboard Email** with real-time feedback toast.
   - Social links (*GitHub*, *LinkedIn*, *X / Twitter*).

6. **Atmospheric Creative Polish**:
   - Dynamic mouse-following ambient glow.
   - Cyberpunk grid background with subtle scanlines.
   - Floating glassmorphism navigation pill with active scroll spy.
   - 100% responsive across mobile, tablet, and ultra-wide displays.

## 🚀 Getting Started

### Development
Start the local Vite development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
Generate an optimized, minified production bundle in `dist/`:
```bash
npm run build
```

### Preview Build
Preview the generated production build locally:
```bash
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Neon Accents & Glassmorphism
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Micro-Interactions**: Canvas Confetti
